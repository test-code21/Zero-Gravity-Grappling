# Positional Atlas of Zero Gravity Grappling

## Purpose

This document begins the first positional grammar of altered-gravity grappling.

A position should be defined by:

- anchor source
- orientation control
- rotation state
- contact points
- controlled axes
- escape routes
- submission risk
- boundary relationship
- energy state

## Position Families

### 1. Free-Space Positions

Positions away from walls or tethers.

- Free Float Neutral
- Mirror Float
- Anchor Clinch
- Floating Guard
- Axis Control
- Rotational Back Control
- Spin Shell

### 2. Wall Positions

Positions using the chamber surface as the new mat.

- Wall Pin
- Wall Mount
- Wall Frame Recovery
- Corner Compression
- Surface Ride
- Rebound Guard

### 3. Tether Positions

Positions involving straps, handles, suit grips, or arena anchors.

- Tether Clinch
- Anchor Loop Control
- Line Trap
- Tether Guard
- Pendulum Escape
- Two-Point Suspension Pin

### 4. Rotational Positions

Controlled movement states where rotation itself is part of the position.

- Axis Lock
- Corkscrew Ride
- Spin Dampening Frame
- Counter-Rotation Guard
- Orbital Pass
- Gyro Back Control

### 5. Recovery Positions

Defensive states for restoring orientation, safety, and control.

- Shell Recovery
- Starfish Brake
- Knee-Elbow Sphere
- Wall Catch
- Breath Reset
- Visual Horizon Lock

## Foundational 12

| # | Position | Core Meaning |
|---:|---|---|
| 1 | Free Float Neutral | No dominant grips; both athletes drifting or orienting. |
| 2 | Mirror Float | Athletes face each other with matched orientation and distance. |
| 3 | Anchor Clinch | Body grips create a shared anchor. |
| 4 | Floating Guard | Defensive leg/arm structure controls distance without a floor. |
| 5 | Axis Control | One athlete controls the opponent’s rotational line. |
| 6 | Rotational Back Control | Back control focused on spine-line and spin control. |
| 7 | Wall Pin | Opponent stabilized against a padded surface. |
| 8 | Wall Mount | Chest/hip dominance against a wall with rebound control. |
| 9 | Wall Frame Recovery | Defensive frame using wall contact to prevent pin or submission. |
| 10 | Spin Shell | Compact defensive posture used to slow rotation and protect limbs. |
| 11 | Tether Clinch | Control relationship involving a strap, handle, or arena anchor. |
| 12 | Stabilized Submission Control | Submission threat only after safe immobilization is established. |

## Position Template

For each position, document:

- Definition
- Objective
- Contact points
- Controlled axes
- Center-of-mass relationship
- Dominant athlete’s goal
- Defensive athlete’s goal
- Common entries
- Common escapes
- Safety risks
- Possible scoring value
- Visualization potential
