# Decade Capstone Template

## 1. What Changed

Summarize the material changes to project current truth during the Decade.

Do not summarize activity for its own sake.

Focus on:

- knowledge gained
- uncertainties reduced
- assumptions falsified
- doctrine revised
- artifacts that became useful
- artifacts that became obsolete

## 2. Evidence Ledger

For each consequential conclusion:

| Conclusion | Evidence | Confidence | What would change our mind? |
|---|---|---|---|

Separate established science, inference, design proposal, and speculation.

## 3. Work Quality Review

Assess:

- quality-adjusted useful work
- evidence quality
- downstream usefulness
- error correction
- unnecessary duplication
- dead ends
- agent-hours consumed
- human judgment consumed
- avoidable escalations

## 4. Current Truth Update

Produce a revised current-truth snapshot reflecting the work actually completed.

The capstone must not preserve stale doctrine for continuity's sake.

## 5. Remaining Frontier

Rank the most consequential unresolved questions remaining after the Decade.

For each, include:

- why it matters
- current uncertainty
- what evidence could resolve it
- dependencies
- whether it is currently executable

## 6. Proposed Next Decade

Propose the next ten forecasted work states.

The next Decade must be derived from the updated current truth, not copied forward from the old forecast.

Only the front edge should be recommended for immediate admission.

## 7. Judgment Gate

State whether founder input is actually required.

If yes, ask only for the minimum consequential judgment that cannot be reasonably inferred from existing intent.

If no, explicitly recommend autonomous continuation.
